# Wailord Clock
A Clock featuring Octillery and Wailord, as Octillery supports Wailord to float in air!

Featuring a TFT screen, 4 keys and 1 buzzer (alarm)

# Main features
+ 4 programable buttons for keys
+ 1 OLED display for Time/Animation 
+ 1 Alarm Buzzer

# CAD models
Full model was first made in Blender, then ported into Fusion 360 to convert to parametric mesh.
The Octillery Tentacules is where the usb c and jumper wires will go through. (hollow)
